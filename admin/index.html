Connect your GitHub

The admin saves changes by updating your site's files on GitHub. It needs a key that only lets it edit this one website. You make it once; it's stored only in this browser.

  1. Open GitHub → New fine-grained token.
  2. Token name: Website admin. Expiration: 90 days.
  3. Repository access: Only select repositories → Portfolio_Website.
  4. Permissions → Repository → Contents: Read and write.
  5. Tap Generate token, copy it, and paste it below.
